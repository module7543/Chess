\# Chess Game



\## What this is

A chess game that runs in a web browser. It is a single HTML file in this folder. Open it by double-clicking it. No install or server is needed.



\## Features

\- Two-player mode: two people take turns on the same screen.

\- Play vs computer (in progress): the human plays White and the computer plays Black.

\- Standard chess rules, including check, checkmate, castling, en passant, and pawn promotion.

\- Shows whose turn it is.

\- Highlights legal moves when a piece is selected.
